Cadastrar equipes

No menu, escolha a opção de cadastro de equipes.
Digite o nome de cada equipe.
Exemplo: Falcões, Corujas, Pixel Squad, Nova Era.
Repita até cadastrar todas as equipes que participarão do festival.
Registrar partidas

Escolha a opção de registrar partida.
Selecione a modalidade:
Futsal
eSports
Escolha duas equipes cadastradas.
Informe o placar:
Futsal: gols ou empate
eSports: resultado de uma série melhor de três mapas
O sistema registra a partida no histórico.
Consultar o histórico

No menu, escolha a opção de consultar histórico.
O sistema exibirá todas as partidas registradas com:
modalidade
equipes
placar
vencedor ou empate
Cadastrar o festival

Escolha a opção de cadastro do festival.
Informe:
nome do festival
local
data
horário
O sistema valida os dados antes de armazená-los.
Gerar cartão do convite

Escolha a opção para gerar o convite do festival.
O programa exibirá o cartão com:
nome do evento
local
data
horário
Gerar cartão de uma partida

Escolha a opção para gerar cartão de resultado.
Selecione uma partida registrada no histórico.
O sistema mostrará um cartão textual com os dados do resultado.
Encerrar o programa

Escolha a opção sair no menu.
O programa encerra a execução.
